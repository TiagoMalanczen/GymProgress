# 🏋️ GymProgress - Sistema de Gestão de Treinos e Avaliação Física

Aplicação desenvolvida em Java utilizando os pilares da Orientação a Objetos para automatizar o gerenciamento de rotinas de treinamento, controle de equipes técnicas e monitoramento físico de alunos em academias.

## 🎯 Escopo do Sistema
* **Modelagem em Camadas:** Arquitetura dividida em módulos isolados de dados, regras de negócio em memória e interface com o usuário.
* **Gestão de Usuários:** Hierarquia estruturada para diferenciação e controle de perfis de alunos e instrutores com identificadores únicos automáticos.
* **Planejamento de Treinos:** Sistema modularizado de montagem de fichas e cargas de trabalho baseado na combinação de grupos musculares e exercícios.
* **Avaliação Física:** Motor de inteligência para processamento, cálculo e classificação imediata de índices de massa corporal (IMC).

## 📂 Visão Geral da Arquitetura
- **Módulo de Entidades:** Definição estrutural de dados, herança, composições e tabelas de domínio do sistema.
- **Módulo de Serviço:** Centralização da inteligência de negócios, algoritmos de busca e processamento de dados nas coleções.
- **Módulo de Visão:** Interface de interação com o usuário final via console para navegação fluida de funcionalidades.
